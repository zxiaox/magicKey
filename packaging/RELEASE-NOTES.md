MagicKey v1.8.1

- New profiles use Q → Numpad 7, W → Numpad 8, R → Numpad 4, T → Numpad 5. The dedicated keypad edits the input key for each keypad destination; unassigned 1/2 fields are blank. Existing custom mappings are retained.
- Key Mapping displays four rows; combinations display at least two rows.
- Mapping rows now contain no native text labels; custom rendering supplies visible text, preventing native label tips.

Download the portable ZIP or MagicKey.exe. Update through Settings → Check for updates.
